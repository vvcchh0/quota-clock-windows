# Windows 额度时钟

把 AI 额度映射为传统三针表盘，再将秒针尖端的纵向位置画成滚动轨迹。

## 指针与轨迹

数字与外环保留官方剩余额度。指针随已消耗额度顺时针前进：时针每 100% 一圈，分针每 10% 一圈，细针每 1% 一圈。它们不显示现实时间。

新点固定在表盘旁，纵坐标与细针尖端高度一致。历史默认向右滚动，可左右镜像；每格五分钟，格宽等于表盘半径，显示最近十五分钟。匀速消耗 1% / 五分钟时，每格形成一个余弦周期。

每十五秒采样一次，点之间按额度相位插值。这是视觉轨迹，不是对采样间真实用量的还原。缺失、休眠、来源变化、校准回调及大跳变会断线。

## 使用与构建

需要 Windows 10/11 x64、.NET Framework 4.8，以及已安装并登录的 Codex。运行：

```powershell
.uild.ps1
.\QuotaClock.exe
```

使用系统自带 csc，无需安装 .NET SDK 或 NuGet 依赖。程序目录需要可写；更新可执行文件前先退出旧实例。

- 拖动表盘或轨迹移动组件；双击打开详情，右键进入设置或退出。
- 设置 → 通用：刷新周期、后台连接与主题。
- 设置 → 悬浮窗：轨迹开关、镜像方向、大小和透明度。
- 设置 → 数据来源 → 演示模式 → 播放演示：立即查看明确标记的十五分钟示例波形。

真实轨迹从启动后积累，退出清空；关闭详情和设置仍在托盘运行。任务栏嵌入只在一套 Windows 11 环境验证过，多屏、混合 DPI、Explorer 重启等需要更广泛测试。

## 精度和隐私

当前官方额度通常为整数。实验性细针优先用本地真实小数，否则根据本地 token、模型权重与观察到的官方额度变化校准，以琥珀色虚线表示；数据不足或不稳时暂停。它没有官方亚百分比精度，不能用固定 API 单价直接折算订阅额度。数字读数始终保留官方值。

官方读取通过本机 Codex app-server，仅发送初始化和只读额度请求，不发起模型生成。可选估算会读取本地会话日志提取用量字段，不上传日志、不改写会话、不直接读取认证文件。更多见[隐私说明](docs/PRIVACY.md)。

## 性能与验证

默认十五秒更新，复用 stdio 连接；超时、错误后回收并退避。CLI 私有缓存超过 96 MiB 或累计读取 120 次时重建。工作集回收只作用于自有闲置子进程，并不代表释放全部私有提交内存。

一轮本机短测中，平均总 CPU 从约 0.119% 降至 0.015%；平均工作集由约 115.8 降至 113.1 MiB，主要收益在 CPU，内存基本同量级。[方法和适用范围](docs/PERFORMANCE.md)。

运行 `test.ps1` 可执行 101 项检查。假接口测试不访问账号。
